==== Share chain / node work

[cols="1,2,8"]
|===
|PR |Author |Title / description

|https://github.com/p2poolv2/p2poolv2/pull/711[#711]
|pool2win
a|*Prune block data below prune depth*

* Background task deletes block bodies more than `PRUNE_DEPTH +
  PRUNE_INTERVAL` below the confirmed tip; headers and merkle branches are
  kept so pruned nodes still serve header sync from genesis. Prune config
  moved into code constants.
* Candidate chain refuses reorgs whose fork point is below the prune target
  (or within `MAX_UNCLES_DEPTH` of it).
* New sim runs (normal pruning, a node joining after others pruned, forks
  in nightly) and design docs in `docs/architecture/pruning.md`. Closes
  #592.

|https://github.com/p2poolv2/p2poolv2/pull/712[#712]
|pool2win
a|*Move genesis data to dat files*

* Genesis shares as raw `.dat` files instead of hex strings in `.rs` –
  hex troubled editors and took twice the space. Also fixes testnet4
  genesis hash/height.

|https://github.com/p2poolv2/p2poolv2/pull/719[#719]
|pool2win
a|*Add dns seed for easier node setup*

* Built-in per-network DNS seeds (testnet4: `seed.testnet4.p2poolv2.org`),
  used only as a fallback: at startup with no `dial_peers`, or 10s after
  startup when none of the `dial_peers` connected. At most 16 addresses
  per seed; `network.dns_seed` (default `true`) turns it off.
* `dial_peers` now optional; a node without `listen_address` still dials
  out. For #717.

|https://github.com/p2poolv2/p2poolv2/pull/715[#715]
|pool2win
a|*Fix hydrapool pplns session difficulty*

* In Hydrapool mode a PPLNS share was stored and credited at the full
  session difficulty even when its hash didn't meet it (since share chain
  emissions were added). Now stored only when it meets session difficulty.
* Hydrapool shares go to a new dedicated PPLNS share worker and are never
  emitted to the share chain; emission worker refactored.
